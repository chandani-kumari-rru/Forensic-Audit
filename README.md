# Forensic Audit
- it is mix of accounting + law.
- The goal is to find proof of financial crimes.
- Result can be used in court of law.
- In Single line say "A Forensic Audit is a detailed review of an `organiation's financial records` & transactions to find financial irregularities.

### Forensic Fraud Detection Tool
|Tools|Description|
|---|---|
|ACL Analytics |Offers Advanced data analysis features that allow forensic auditors to examine financial records & transaction for irregularities |
|CaseWare IDEA |Data Analytics tool used to extract, analyze & visualize data in real-time, helping auditors spot fraudulent patterns |
|SAS Fraud Management |A sophisticated fraud detection system that uses AI to analyze transaction & prevent in banking & financial institutions|
